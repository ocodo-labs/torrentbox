# TorrentBox

Manage torrents in Transmission with AI helpers, the focus is on file naming and moving to the right place in your media archive.

## Install

Clone this repo and run:

```sh
npm install
npx next
```

![](TorrentBox-dark.png)

View the torrent files

![](TorrentBox-torrent-files.png)

You can the rename torrent files and AI will suggest ideas, it'll try to remove crud from the filename.
